# StockFloat

[English](README.md)

一个 macOS 置顶悬浮小窗，实时显示你关注的股票的价格和涨跌幅。它停在屏幕右上角，在所有桌面和全屏应用上都可见，并且不会抢走键盘焦点。

- 支持美股、港股、A 股
- 接入长桥后，每只美股多一行显示盘前、盘后、夜盘价格
- 中英文界面
- 没有 Dock 图标，也没有菜单栏图标，所有操作都在小窗的右键菜单里

## 为什么做这个

我做美股，vibe coding 的时候想随时知道手里几只标的的价格。以前有两种看法，都不好用：

- **切到券商 App 或网页去看。** 每看一眼都要离开手头的窗口。
- **开着一个行情窗口。** 它占屏幕，而且还是会被别的窗口盖住。

我要的其实比这两样都少：关注的那几只股票，现价和涨跌幅，一直停在屏幕角落里，不用点任何东西就能看到。

系统自带的几种办法也不合适。带刘海的 MacBook 菜单栏位置很紧，想显示多只股票就得做成下拉菜单，那又多了一次点击。桌面小组件最快也要几分钟才刷新一次。终端窗口没法一直浮在别的窗口上面。

所以有了 StockFloat：一个浮在所有窗口之上的小窗，只做这一件事。

## 设计取舍

- **一直看得见，但不碍事。** 小窗浮在每个桌面和全屏应用之上，从不抢键盘焦点，还可以让鼠标点击直接穿过它。
- **只给一眼能看完的信息。** 每只股票一行：名称、价格、涨跌幅。没有图表、新闻和下单，这些券商 App 做得更好。
- **不假装实时。** 看起来在跳、其实已经过期的价格，比没有价格更糟。数据源断开时小窗会直接写出来；盘前、盘后、夜盘的价格单独一行并标明时段；下面的数据源表格写明了每个来源有多新。
- **够小。** 它要挂一整天，所以用原生 Swift 写：常驻内存约 17MB，应用本体约 1.6MB。
- **不保管券商凭证。** 长桥的登录留在长桥自己的命令行工具里，StockFloat 只是启动它并读取行情。

## 安装

需要 macOS 14 或更高版本。安装包同时支持 Apple 芯片和 Intel 芯片的 Mac。

1. 在 [Releases](../../releases) 页面下载 `StockFloat-<版本号>.zip`。
2. 解压，把 `StockFloat.app` 拖进「应用程序」文件夹。
3. 打开它。第一次打开请看下一节。

### 首次打开

StockFloat 没有经过 Apple 公证，所以第一次打开时会被 macOS 拦截。放行方法：

1. 打开一次 StockFloat，关掉弹出的警告。
2. 打开**系统设置 → 隐私与安全性**，滚动到**安全性**，在 StockFloat 那条提示旁点**仍要打开**。

或者在终端里去掉下载标记：

```sh
xattr -dr com.apple.quarantine /Applications/StockFloat.app
```

每次下载只需要做一次。

## 使用

StockFloat 在菜单栏有一个折线图标，默认在 Dock 里也有图标。点其中任何一个，或者右键小窗，都能打开菜单：

- **设置…**：编辑标的列表和数据源。
- **隐藏小窗** / **显示小窗**。在任何应用里按 **⌃⌥S** 效果相同；点 Dock 图标或再次打开 StockFloat 也会让隐藏的小窗重新出现。
- **外观**：设置配色（绿涨红跌、红涨绿跌、不着色）、字号和不透明度。
- **语言**：在跟随系统、中文、English 之间切换。
- **鼠标穿透**：点击会穿过小窗；按住 ⌥ 可以临时操作它。
- **在 Dock 中显示图标**：关掉或打开 Dock 图标；菜单栏图标始终保留。
- **开机启动**

拖动小窗可以移动位置，位置会被记住。

美股在常规时段之外会多出第二行：太阳图标是盘前，日落是盘后，月亮是夜盘，后面是该时段的价格和相对收盘价的涨跌幅。

价格超过 30 分钟没有更新时，那一行会变暗；休市、午休、断线都是这个样子。

### 标的格式

在设置里每行写一个：

| 市场 | 格式 | 示例 |
| --- | --- | --- |
| 美股 | 股票代码 | `AAPL` |
| 港股 | `hk` 加 5 位数字 | `hk00700` |
| 沪市 | `sh` 加 6 位数字 | `sh600519` |
| 深市 | `sz` 加 6 位数字 | `sz000001` |

配置保存在 `~/.config/stock-float/config.json`。想换快捷键，改里面的 `hotkey`（例如 `"cmd+shift+9"`，留空 `""` 则不启用），然后重启应用。

## 数据源

| 数据源 | 市场 | 需要准备 | 实时性 |
| --- | --- | --- | --- |
| 腾讯（默认） | 美股、港股、A 股 | 无 | 美股约 20 秒一次快照 |
| 长桥 | 美股 | 长桥账户和它的 CLI | 逐笔推送，含盘前、盘后、夜盘 |
| Finnhub | 美股 | 免费的 API key | 逐笔推送，常规时段 |

腾讯的接口是非官方的，可能随时变动。

### 长桥

```sh
brew install --cask longbridge/tap/longbridge-terminal
longbridge auth login
```

然后在设置里打开**美股使用长桥行情**。账户需要有 US LV1 (OpenAPI) 行情权限。StockFloat 在后台运行 `longbridge serve`，自己不保存任何长桥凭证。

### Finnhub

把 [finnhub.io](https://finnhub.io) 的 key 填进设置。长桥开关关闭时，美股行情会用它。

## 从源码构建

需要 Xcode 16 或更高版本。

```sh
swift test
./scripts/bundle.sh             # 为本机构建 build/StockFloat.app
./scripts/bundle.sh --universal # 同时支持 Apple 芯片和 Intel
```

图标由 `scripts/make-icon.swift` 从 `Resources/icon-source.png` 生成，换图后重新运行即可。

发布新版本时给版本打 tag，GitHub Actions 会构建通用版本并附到 release 上：

```sh
./scripts/release.sh 0.2.0
```
